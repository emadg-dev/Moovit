# تکون بده (MoveBreak) — یادآور تحرک پشت میز

> **«یه کم تکون بخور، حالت جا میاد!»**  
> اپلیکیشن پیش‌رونده (PWA) اختصاصی برای یادآوری برخاستن از پشت میز، کشش عضلات، قدم زدن و حفظ سلامتی، طراحی‌شده با زبان فارسی و راست‌چین (RTL)، تم آرامش‌بخش بنفش پاستلی و کاراکتر دوست‌داشتنی «تکونی».

---

## ۱. ویژگی‌های کلیدی

- **طراحی موبایل‌محور (Mobile-First)**: بهینه‌سازی‌شده برای ابعاد صفحه، ژست‌های حرکتی و حاشیه‌های امن (Safe Area) آیفون ۱۵ و تمام گوشی‌های هوشمند.
- **کاملاً فارسی و راست‌چین (RTL)**: لحن صمیمی، دوستانه و خودمانی همراه با قالب‌بندی اعداد به ارقام فارسی (`۰ تا ۹`).
- **کاراکتر اختصاصی «تکونی»**: ۶ حالت بصری برداری (SVG) شامل حالت عادی (`idle`)، کشش دست‌ها (`stretch`)، قدم زدن (`walking`)، استراحت بعد کار (`sleepy`)، جشن موفقیت (`celebrate`) و ریلکسیشن (`resting`).
- **سیستم حساب کاربری (ثبت‌نام و ورود)**: امکان ساخت حساب کاربری، ورود امن، شخصی‌سازی پروفایل و ذخیره سوابق و زنجیره در سرور با پایگاه داده SQLite و حالت مهمان (Guest) بدون اجبار به ثبت‌نام.
- **زنجیره روزهای متوالی (Streaks) با آیکون شعله آتش 🔥**: ردیابی تعداد روزهای متوالی که کاربر به هدف استراحت روزانه خود رسیده است همراه با ثبت رکورد بیشترین زنجیره (Best Streak).
- **پشتیبانی از اعداد انگلیسی و فونت IRANSans**: نمایش یکدست ارقام و متن با فونت ایران‌سنس.
- **معماری سه‌لایه اعلان‌ها**:
  1. **لایه اول (تایمر درون‌برنامه‌ای دقیق)**: محاسبه بر اساس مُهر زمانی (`timestamp`) و مقاوم در برابر به‌خواب رفتن یا تعویض تب مرورگر.
  2. **لایه دوم (اعلان‌های مرورگر و صدای چایم)**: صدای ملایم سنتزشده با Web Audio API (بدون فایل صوتی خارجی و سبک) همراه با اعلان مرورگر.
  3. **لایه سوم (وب‌پوش پس‌زمینه با سرور اختیاری و SQLite)**: ارسال اعلان به گوشی و سیستم حتی در زمان بسته بودن کامل برنامه.
- **دیتابیس SQLite در سرور (`takoon-bede.sqlite`)**: ذخیره اشتراک‌های Push، تنظیمات کاربر، سوابق استراحت و جلوگیری از ارسال اعلان تکراری (`deduplication_key`).
- **محلی‌محور و آفلاین (Offline-First)**: برنامه بدون نیاز به سرور و کاملاً درون مرورگر با `localStorage` و `Service Worker` کار می‌کند.
- **حفظ حریم خصوصی**: بدون ردیاب، بدون ابزارهای تحلیلی، بدون تبلیغات و بدون نیاز به ثبت‌نام یا اکانت کاربری.

## ۳. راهنمای اجرای محلی در ویندوز (Windows) با ابزارهای رایگان

تمام ابزارهای مورد استفاده رایگان هستند و نیازی به مک، Xcode یا اکانت پولی اپل ندارید.

### پیش‌نیازها:
۱. دانلود و نصب **Node.js LTS** (نسخه ۲۰ یا بالاتر) از سایت رسمی: [nodejs.org](https://nodejs.org)  
۲. ویرایشگر کد رایگان **VS Code** (اختیاری): [code.visualstudio.com](https://code.visualstudio.com)

### مراحل اجرا:

۱. ترمینال (PowerShell یا CMD) را در پوشه پروژه باز کنید:
```bash
# نصب وابستگی‌ها
npm install
```

۲. اجرای پروژه در حالت توسعه:
```bash
npm run dev
```
برنامه روی آدرس `http://localhost:3000` اجرا می‌شود و شامل سرور کامل Express، دیتابیس SQLite و فرانت‌اند واکنش‌گرا است.

۳. ساخت نسخه بهینه‌شده تولید (Production):
```bash
npm run build
```

## ۴. نحوه نصب روی آیفون ۱۵ (iOS Safari)

روی سیستم‌عامل iOS، برنامه‌های PWA بدون نیاز به اپ استور از طریق سافاری نصب می‌شوند:

۱. لینک برنامه را در **مرورگر سافاری (Safari)** باز کنید.  
۲. در نوار پایین مرورگر، روی آیکون **اشتراک‌گذاری (Share)** که شبیه یک مربع با فلش رو به بالا است ضربه بزنید.  
۳. به سمت پایین اسکرول کنید و گزینه **Add to Home Screen (افزودن به صفحه اصلی)** را انتخاب کنید.  
۴. نام «تکون بده» نمایش داده می‌شود؛ دکمه **Add** را در بالای صفحه بزنید.  
۵. آیکون برنامه روی صفحه اصلی گوشی شما ظاهر می‌شود و مانند یک برنامه نیتیو و تمام‌صفحه باز خواهد شد.

> **نکته در مورد اعلان‌های iOS:** در iOS نسخه ۱۶.۴ به بعد، وب‌پوش پس‌زمینه تنها زمانی فعال می‌شود که برنامه ابتدا به Home Screen اضافه شده باشد و کاربر دکمه فعال‌سازی اعلان را داخل همان برنامه نصب‌شده لمس کند.

## ۵. دیتابیس SQLite و معماری وب‌پوش (Web Push)

دیتابیس در فایل `takoon-bede.sqlite` نگهداری می‌شود و شامل ۴ جدول استاندارد است:
- `user_settings`: تنظیمات کاربر شامل بازه استراحت، ساعت کاری، روزهای فعال و منطقه زمانی (Timezone).
- `push_subscriptions`: اندپوینت‌ها و کلیدهای رمزنگاری P-256DH اشتراک مرورگرها.
- `completed_breaks`: سابقه استراحت‌های موفق همراه با ساعت دقیق.
- `notification_deliveries`: گزارش تحویل اعلان‌ها با کلید یکتا (`deduplication_key`) جهت جلوگیری از ارسال تکراری در یک بازه زمانی.

### تولید کلیدهای VAPID شخصی (اختیاری):
کلیدهای VAPID به‌طور خودکار در صورت عدم وجود تولید می‌شوند. برای تولید دستی:
```bash
npx web-push generate-vapid-keys
```
سپس مقادیر تولیدشده را در فایل `.env` قرار دهید:
```env
VAPID_PUBLIC_KEY="کلید_عمومی_شما"
VAPID_PRIVATE_KEY="کلید_خصوصی_شما"
VAPID_SUBJECT="mailto:your-email@example.com"
```

## ۶. راهنمای دیپلوی و میزبانی رایگان

### الف) هاستینگ کاملاً رایگان استاتیک (GitHub Pages یا Cloudflare Pages)
اگر فقط می‌خواهید فرانت‌اند PWA و تایمرهای داخلی فعال باشند:
۱. دستور `npm run build` را اجرا کنید تا پوشه `dist` ساخته شود.
۲. محتویات پوشه `dist` را روی **Cloudflare Pages** یا **GitHub Pages** بارگذاری کنید.
۳. نیازی به تنظیمات پیچیده سرور نیست و روی دامنه رایگان HTTPS اجرا می‌شود.

### ب) دیپلوی فول‌استک با سرور و دیتابیس پایدار (Persistent SQLite)
از آنجا که دیتابیس SQLite یک فایل فیزیکی روی دیسک است، برای حفظ دائمی اشتراک‌ها در ری‌استارت‌های سرور:
- در سرویس‌هایی مانند **Render** یا **Fly.io**، حتماً یک **Persistent Disk** (دیسک پایدار) برای مسیر فایل `takoon-bede.sqlite` اختصاص دهید، زیرا فضاهای ذخیره‌سازی رایگان اپفمرال (Ephemeral) با هر ری‌استارت محتویات را پاک می‌کنند.
- همچنین می‌توانید آن را روی هر سرور شخصی یا VPS ارزان‌قیمت با داکر یا PM2 به‌سادگی اجرا کنید:
```bash
npm run start
```

## ۸. حریم خصوصی

تمام داده‌های استفاده شما شامل ساعت‌های استراحت، ساعات کاری و فعالیت‌ها فقط و فقط در دستگاه خودتان نگهداری می‌شوند. در صورت فعال‌سازی وب‌پوش، صرفاً شناسه فنی ناشناس اشتراک به سرور ارسال می‌شود تا امکان فرستادن یادآور وجود داشته باشد. هیچ نام، ایمیل، شماره تلفن یا موقعیت مکانی از شما دریافت یا ذخیره نمی‌شود.
